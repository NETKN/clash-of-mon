# ศึกหกธาตุ

เกมดวลมอนสเตอร์ 1 ต่อ 1 แบบเรียลไทม์ ภาพพิกเซลมองจากด้านบน เล่นได้บนมือถือและคอมพิวเตอร์ ไม่ต้องติดตั้งและไม่ต้องสมัครสมาชิก

## วิธีเล่น

1. เลือกมอนสเตอร์ 1 ใน 6 ธาตุ (ไฟ น้ำ พืช สายฟ้า ดิน ลม)
2. จัดท่าติดตัว 4 ท่าจาก 9 ท่าของแต่ละตัว
3. กด **ฝึกกับบอท** หรือ **สร้างห้อง** แล้วส่งรหัส 4 ตัวหรือลิงก์เชิญให้เพื่อน

| | คอมพิวเตอร์ | มือถือ |
|---|---|---|
| เดิน | W A S D หรือปุ่มลูกศร | จอยสติ๊กซ้ายมือ |
| ใช้ท่า | J K L ; หรือ 1–4 | ปุ่มท่าขวามือ |
| หลบ | Space | ปุ่มหลบ |

## แพ้ชนะธาตุ

ชนะทาง ×1.5 · แพ้ทางหรือธาตุเดียวกัน ×0.6 · ท่าธาตุเดียวกับตัวละครแรงขึ้น 25%

| ธาตุ | ชนะ |
|---|---|
| ไฟ | พืช ลม |
| น้ำ | ไฟ ดิน |
| พืช | น้ำ ดิน |
| สายฟ้า | น้ำ ลม |
| ดิน | ไฟ สายฟ้า |
| ลม | พืช ดิน |

## โครงสร้างทางเทคนิค

- ทั้งเกมอยู่ใน `index.html` ไฟล์เดียว ไม่มีขั้นตอน build
- ผู้เล่นสองคนเชื่อมต่อกันโดยตรงผ่าน WebRTC ด้วยไลบรารี [PeerJS](https://peerjs.com) และใช้เซิร์ฟเวอร์จับคู่สาธารณะของ PeerJS เฉพาะตอนเริ่มเชื่อมต่อ
- แต่ละเครื่องจำลองมอนสเตอร์ของตัวเองและเป็นผู้ตัดสินว่าตัวเองโดนโจมตีหรือไม่ แล้วส่งตำแหน่ง พลังชีวิต และรายการท่าล่าสุดให้อีกฝั่งประมาณ 20 ครั้งต่อวินาที
- เครือข่ายที่ปิดกั้นการเชื่อมต่อแบบตรง เช่น ไฟร์วอลล์องค์กรบางแห่ง อาจเข้าห้องไม่ได้
