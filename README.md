# Clash of Mon

Realtime 1-on-1 monster showdown

เกมดวลมอนสเตอร์ธาตุผสม 1 ต่อ 1 แบบเรียลไทม์ ภาพพิกเซลมองจากด้านบน เล่นได้บนมือถือและคอมพิวเตอร์ ไม่ต้องติดตั้งและไม่ต้องสมัครสมาชิก

เล่นได้ที่ https://netkn.github.io/clash-of-mon/

## วิธีเล่น

1. กด START แล้วตั้งชื่อผู้เล่นสำหรับรอบนั้น
2. เลือกมอนสเตอร์ 1 ใน 12 ตัว แต่ละตัวมี 2 ธาตุ มีท่าโจมตีพื้นฐานและท่าไม้ตายเป็นของตัวเอง
3. จัดสกิล 3 ช่องจากท่าของทั้งสองธาตุและท่าทั่วไป รวม 17 ท่าต่อตัว
4. เลือกสนาม แล้วกด **ฝึกกับบอท** หรือ **สร้างห้อง** เพื่อส่งรหัส 4 ตัวหรือลิงก์เชิญให้เพื่อน

## การบังคับ

| เล็ง | เมาส์ | แตะปุ่ม = เล็งให้เอง · ลากปุ่ม = เล็งเอง |
| โจมตีพื้นฐาน | คลิกซ้ายค้าง | ปุ่มใหญ่ขวาล่าง |
| สกิล | Q E R กดค้างเพื่อดูแนวเล็ง ปล่อยเพื่อใช้ | ปุ่มสกิล 3 ปุ่ม ปล่อยนิ้วเพื่อใช้ |
| ท่าไม้ตาย | F (ท่าที่ยิงต่อเนื่องหมุนทิศตามเมาส์) | ปุ่มท่าไม้ตาย (ลากปุ่มค้างเพื่อหมุนทิศระหว่างยิง) |
| หลบ | Space | ปุ่มหลบ |

## มอนสเตอร์

| ชื่อ | ธาตุ | โจมตีพื้นฐาน | ท่าไม้ตาย |
|---|---|---|---|
| ไพรอส | ไฟ / ลม | ขนเพลิง (ยิง) | **วิหคเพลิงผลาญฟ้า**: ทะยานขึ้นฟ้ากลายเป็นวิหคเพลิงยักษ์ โฉบกวาดผ่านจุดเล็ง 3 รอบเป็นรูปดาว แล้วจุติลงมาระเบิดพร้อมฟื้นพลัง |
| ครัสต้า | น้ำ / ดิน | ก้ามหนีบ (ประชิด) | **กระดองเพชรคลื่นคลั่ง**: หดเข้ากระดองหมุนโต้คลื่น บังคับทิศเองได้ ชนซ้ำได้ เด้งกำแพง สาดเศษผลึก |
| เมฆา | สายฟ้า / ลม | ประกายเขา (ยิง) | **เมฆาพิโรธ**: เมฆพายุยักษ์ลอยไล่ตามคู่ต่อสู้ ฝนทำให้ช้า ฟ้าผ่าไม่หยุด ปิดท้ายด้วยอสนีบาตยักษ์ |
| พริกกี้ | พืช / ไฟ | พ่นเมล็ด (ยิง) | **มหาพริกนรกแตกหน่อ**: พริกยักษ์ตกลงจุดเล็ง ระเบิดแล้วแตกหน่อเป็นพริกลูกเล็กระเบิดต่อกันสองวง |
| ศิลา | ดิน / พืช | หมัดศิลา (ประชิด) | **ร่างยักษ์ศิลาพันปี**: ขยายร่างเป็นยักษ์หิน 7 วินาที เกราะหนา ไม่ติดมึน หมัดกว้าง ทุกก้าวแผ่นดินไหว |
| อีลล่า | น้ำ / สายฟ้า | พ่นน้ำ (ยิง) | **มังกรอัสนีวารี**: อัญเชิญมังกรสายฟ้าตัวยาวว่ายไล่ล่าคู่ต่อสู้ ฟาดซ้ำได้ ช็อตแม่น้ำ |
| ฟูวา | ลม / น้ำ | เป่าลม (ยิง) | **ฟองนภากักขัง**: ฟองยักษ์ 5 ลูกลอยไล่ โดนแล้วถูกขังลอยกลางอากาศ ฟองที่เหลือพุ่งเข้าระเบิดซ้ำ |
| ลาวาร็อก | ไฟ / ดิน | เขาลาวา (ประชิด) | **มหาภูเขาไฟพิโรธ**: กลายเป็นภูเขาไฟ ลาวาแผ่ขยายรอบตัว พ่นระเบิดลาวาใส่คู่ต่อสู้ตลอดเวลา |
| เบลซาร์ | ไฟ / โลหะ | ลูกไฟรัว (ยิง) | **นรกเพลิงคราม**: รัวลูกไฟยักษ์ 22 ลูก ร้อนขึ้นจนกลายเป็นเปลวไฟสีฟ้า หมุนทิศยิงได้ตามที่เล็ง |
| เรย่า | น้ำ / ลม | ลูกน้ำวน (ยิง) | **มหาอุทกภัย**: น้ำท่วมทั้งสนาม คู่ต่อสู้ช้าลง ไฟและลาวาดับ เกลียวน้ำ 3 ลำไล่ดูด |
| เทอร์รัน | ดิน / พืช | ทุบพสุธา (ประชิด) | **คุกศิลาพันปี**: เสาหินล้อมจุดเล็งเป็นกรง หนามรากไม้ผุด 3 ระลอก แล้วหินยักษ์ถล่มกลางกรง |
| อัมบร้า | สายฟ้า / เงา | กรงเล็บเงา (ประชิด) | **เงาอัสนีสามภพ**: ลอยร่ายวงเวทย์ (อมตะระหว่างร่าย) เรียกร่างเงา 3 ร่าง HP ครึ่งหนึ่ง ตีแรงเท่าร่างต้น พุ่งสายฟ้าใส่ศัตรู |

## สนาม

สนามมีขนาด 960×600 กว้างกว่าจอ กล้องตามตัวผู้เล่น

| สนาม | กลไก |
|---|---|
| สนามประลอง | ลังไม้พังได้ ถังระเบิดจะระเบิดเมื่อโดนโจมตี |
| ป่าทึบ | ซ่อนตัวในพุ่มไม้และใต้ต้นไม้ได้ ท่าไฟเผาให้ไหม้หายไป |
| แม่น้ำสายฟ้า | ลงน้ำแล้วเดินช้า ท่าสายฟ้าที่โดนน้ำจะช็อตทั้งแม่น้ำ |
| ปากปล่องภูเขาไฟ | บ่อลาวาเผาคนที่เหยียบ ท่าน้ำทำให้ลาวาแข็งชั่วคราว |
| ทะเลสาบน้ำแข็ง | พื้นน้ำแข็งลื่น ท่าไฟละลายน้ำแข็งเป็นแอ่งน้ำ |
| ทะเลทรายเดือด | หลุมทรายดูดทำให้ช้าและดูดเข้ากลาง กระบองเพชรตำคนที่ชน |
| ซากวิหาร | กำแพงหินบังกระสุนและลำแสง มีแท่นวาร์ป 2 จุดเชื่อมถึงกัน |
| หนองพิษ | บึงพิษกัดพลังและทำให้ช้า บ่อน้ำพุกลางสนามฟื้นพลัง |

## โครงสร้างทางเทคนิค

- `index.html` คือหน้าเว็บและส่วนติดต่อผู้ใช้ `game.js` คือตัวเกมทั้งหมด ไม่มีขั้นตอน build
- แสดงผลด้วยเอนจิน [Phaser 4](https://phaser.io) ผ่าน WebGL ภาพตัวละคร ฉาก เอฟเฟกต์ และเสียงทั้งหมดสร้างจากโค้ดตอนเปิดเกม ไม่มีไฟล์ภาพหรือไฟล์เสียง
- ระบบต่อสู้แยกจากส่วนแสดงผล: ตัวจำลองคำนวณตำแหน่ง ท่า และความเสียหาย แล้วฉากของ Phaser วาดตามสถานะนั้นทุกเฟรม
- ผู้เล่นสองคนเชื่อมต่อกันโดยตรงผ่าน WebRTC ด้วยไลบรารี [PeerJS](https://peerjs.com) และใช้เซิร์ฟเวอร์จับคู่สาธารณะของ PeerJS เฉพาะตอนเริ่มเชื่อมต่อ
- แต่ละเครื่องจำลองมอนสเตอร์ของตัวเองและเป็นผู้ตัดสินว่าตัวเองโดนโจมตีหรือไม่ แล้วส่งตำแหน่ง พลังชีวิต และรายการท่าล่าสุดให้อีกฝั่งประมาณ 20 ครั้งต่อวินาที
- เครือข่ายที่ปิดกั้นการเชื่อมต่อแบบตรง เช่น ไฟร์วอลล์องค์กรบางแห่ง อาจเข้าห้องไม่ได้

มอนสเตอร์ทั้งหมดออกแบบขึ้นใหม่สำหรับเกมนี้
