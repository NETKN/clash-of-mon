# Clash of Mon

Realtime 1-on-1 monster showdown

เกมดวลมอนสเตอร์ธาตุผสม 1 ต่อ 1 แบบเรียลไทม์ ภาพพิกเซลมองจากด้านบน เล่นได้บนมือถือและคอมพิวเตอร์ ไม่ต้องติดตั้งและไม่ต้องสมัครสมาชิก

เล่นได้ที่ https://netkn.github.io/clash-of-mon/

## วิธีเล่น

1. กด START แล้วตั้งชื่อผู้เล่นสำหรับรอบนั้น
2. เลือกมอนสเตอร์ 1 ใน 12 ตัว แต่ละตัวมี 2 ธาตุ มีท่าโจมตีพื้นฐานและท่าไม้ตายเป็นของตัวเอง
3. จัดสกิล 3 ช่องจากท่าของทั้งสองธาตุและท่าทั่วไป รวม 17 ท่าต่อตัว
4. เลือกสนาม แล้วกด **ฝึกกับบอท** หรือ **สร้างห้อง** เพื่อส่งรหัส 4 ตัวหรือลิงก์เชิญให้เพื่อน

## สนาม

สนามมีขนาด 960×600 กว้างกว่าจอ กล้องตามตัวผู้เล่น

| สนาม | กลไก |
|---|---|
| สนามประลอง | ลังไม้พังได้ ถังระเบิดจะระเบิดเมื่อโดนโจมตี |
| ป่าทึบ | ซ่อนตัวในพุ่มไม้และใต้ต้นไม้ได้ ท่าไฟเผาให้ไหม้หายไป |
| แม่น้ำสายฟ้า | ลงน้ำแล้วเดินช้า ท่าสายฟ้าที่โดนน้ำจะช็อตทั้งแม่น้ำ |
| ปากปล่องภูเขาไฟ | บ่อลาวาเผาคนที่เหยียบ ท่าน้ำทำให้ลาวาแข็งชั่วคราว |
| ทะเลสาบน้ำแข็ง | พื้นน้ำแข็งลื่น ท่าไฟละลายน้ำแข็งเป็นแอ่งน้ำ |
| ทะเลทรายเดือด | หลุมทรายดูดทำให้ช้าและดูดเข้ากลาง กระบองเพชรตำคนที่ชน |
| ซากวิหาร | กำแพงหินบังกระสุนและลำแสง มีแท่นวาร์ป 2 จุดเชื่อมถึงกัน |
| หนองพิษ | บึงพิษกัดพลังและทำให้ช้า บ่อน้ำพุกลางสนามฟื้นพลัง |

## โครงสร้างทางเทคนิค

- `index.html` คือหน้าเว็บและส่วนติดต่อผู้ใช้ `game.js` คือตัวเกมทั้งหมด ไม่มีขั้นตอน build
- แสดงผลด้วยเอนจิน [Phaser 4](https://phaser.io) ผ่าน WebGL ภาพตัวละคร ฉาก เอฟเฟกต์ และเสียงทั้งหมดสร้างจากโค้ดตอนเปิดเกม ไม่มีไฟล์ภาพหรือไฟล์เสียง
- ระบบต่อสู้แยกจากส่วนแสดงผล: ตัวจำลองคำนวณตำแหน่ง ท่า และความเสียหาย แล้วฉากของ Phaser วาดตามสถานะนั้นทุกเฟรม
- ผู้เล่นสองคนเชื่อมต่อกันโดยตรงผ่าน WebRTC ด้วยไลบรารี [PeerJS](https://peerjs.com) และใช้เซิร์ฟเวอร์จับคู่สาธารณะของ PeerJS เฉพาะตอนเริ่มเชื่อมต่อ
- แต่ละเครื่องจำลองมอนสเตอร์ของตัวเองและเป็นผู้ตัดสินว่าตัวเองโดนโจมตีหรือไม่ แล้วส่งตำแหน่ง พลังชีวิต และรายการท่าล่าสุดให้อีกฝั่งประมาณ 20 ครั้งต่อวินาที
- เครือข่ายที่ปิดกั้นการเชื่อมต่อแบบตรง เช่น ไฟร์วอลล์องค์กรบางแห่ง อาจเข้าห้องไม่ได้

มอนสเตอร์ทั้งหมดออกแบบขึ้นใหม่สำหรับเกมนี้
